# Laboratory Information System

A **desktop application** for managing laboratory patient data, test bookings, and results — built with C# and Windows Forms.

## Features
- 🔐 User authentication (Login / Register)
- 👥 User & patient management (Admin panel)
- 📋 Book and manage lab tests
- 📊 Patient dashboard to view test results
- 🗄️ Local database via SQLite
